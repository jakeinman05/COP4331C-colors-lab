# COLORS Lab

A small full-stack web application built using the LAMP stack.

The application allows users to log in, add colors to their personal collection, and search through colors they have previously added. The project was built as a hands-on exercise in connecting a frontend web interface to a PHP API and MySQL database hosted on a remote Linux server.

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- PHP
- MySQL

### Server
- Linux
- Apache
- LAMP stack

### Development / Version Control
- Git
- GitHub

## Setup
1. Install and configure a LAMP environment (This project was made using digitalocean.com) with the follwing utilities:
 - Apache
 - PHP
 - MySQL

2. Clone this repository (if using a similar remote server, be sure to clone it there with the use of the `scp` command):
`git clone <repository-url>`

3. Configure Apache so that the contents of the `public` directory are accesible through the web server.
